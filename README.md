# 🤖 ClaudeBot for Bedrock by GoldenFrog

Бот-помощник для мира Minecraft Bedrock Edition 1.19.51. Он заходит в мир как отдельный игрок, читает игровой чат и отвечает в нём с помощью Claude. Если владелец мира прямо попросит, бот может выполнить игровые команды, но только после подтверждения.

Сделан для карты [Shop for Ore](https://github.com/goldenfrog-2577/Shop-for-Ore). Учитывает её систему аккаунтов, формат чата и ограничения антифлуда. В другом мире будет работать в «общем» режиме: чат, команды и ответы Claude без особенностей карты.

Проверено на одном реальном компьютере:

* **Toshiba Satellite L650** (Intel Core i5 M480, ~6 ГБ ОЗУ), Windows 10 22H2
* Minecraft Bedrock 1.19.51 для Windows; мир открыт с этого же компьютера (хост)

## ⚠️ Дисклеймер

Использование бота осуществляется на свой страх и риск. Автор не несёт ответственности за возможные последствия.

* Бот с правами оператора может менять мир командами: `/fill`, `/setblock` и т. п. Их **нельзя отменить**. Перед стройкой делайте копию мира.
* Ответы Claude — это ответы языковой модели. Они могут быть неточными, а предложенные команды могут быть ошибочными. Перед `@ok` читайте, что именно бот собирается выполнить.
* `loopback.bat` меняет сетевую изоляцию приложения Minecraft в Windows. Отменить это можно файлом `loopback_off.bat`.

## ⚙️ Требования

* Windows 10/11
* Minecraft Bedrock **1.19.51**, мир открыт для игроков по локальной сети
* [Node.js](https://nodejs.org) LTS
* для ответов в чате — [Claude Code](https://code.claude.com/docs/en/setup) и подписка Claude **Pro или Max** (на бесплатном тарифе Claude Code не работает)
* для команд — права оператора у бота в мире

## 🛠 Возможности

### 💬 1. Чат и журнал
* Весь игровой чат пишется в `chat.log` вместе с сообщениями карты (`tellraw`), формами меню и строкой состояния. Строка состояния записывается только при изменении, а не на каждом тике.
* Ключи перевода из `tellraw` показываются как `{ключ}`, так что в журнале видно, какое сообщение отправила карта.
* Всё, что появится в `commands.txt`, бот выполнит и очистит файл:
  * `/команда` — выполнить команду;
  * `текст` — написать в чат;
  * `#form ID JSON` — ответить на форму, `#quit` — выйти из мира.

### 🧠 2. Claude в игровом чате
Пишешь в чат `@claude <вопрос>`, бот запускает Claude Code в режиме без интерфейса и отправляет ответ в чат.

* **Без инструментов**: Claude запускается с `--tools ""` в пустой папке `claude_sandbox`. Он не видит ни файлов компьютера, ни мира, только текст.
* **Личность и знание карты** берутся из [persona.md](./persona.md). Личное (кто владелец, его ник) лежит в `persona.local.md`, его в репозитории нет, пример — [persona.local.example.md](./persona.local.example.md). Оба файла перечитываются на каждый вопрос, менять их можно без перезапуска.
* **Контекст**: последние 20 строк чата и память разговора — последние 12 пар «вопрос — ответ» из `dialog.jsonl`.
* **Модель** по умолчанию Haiku: быстрее и экономнее по лимиту. Меняется в `config.json`.
* **Звать может только владелец**: список ников в `claude.owners`.
* Префикс `@`, а не `!`: команды с `!` карта Shop for Ore перехватывает как свои.

### 🛡️ 3. Команды только с подтверждением
Если владелец прямо просит действие («дай мне алмазов», «сделай день»), Claude отвечает текстом и предлагает команды. Сам бот их не выполняет:

```
Steve:     @claude дай мне 5 алмазов и сделай день
ClaudeBot: Предлагаю выполнить (2): /give Steve diamond 5 ; /time set day
ClaudeBot: Подтверди: @ok — выполнить, @no — отмена (120 сек)
Steve:     @ok
```

* **Белый список**: tp, time, weather, give, effect, gamemode, say, title, playsound, particle, summon, setblock, fill, clear, enchant, xp, spawnpoint. Остальное (`/kill`, `/function`, `/scoreboard`, `/op` и т. д.) отклоняется ещё до показа.
* **Лимиты**: `/fill` — не больше 4096 блоков, не больше 10 команд за ответ, подтверждение действует 2 минуты.
* Подтверждать (`@ok` / `@no`) может только владелец.
* Отклонённые команды пишутся в `chat.log` с причиной.

### 🧩 4. Особенности Shop for Ore
* **Аккаунт**: при первом входе бот ждёт регистрации, её проходят вручную через `#form`. Потом бот сам отвечает на окно входа паролем из `bot_account.txt`.
* **Формат чата карты** (`время [ранг] | [уровень] Ник ➜ текст`, где значки — глифы шрифта карты) разбирается отдельно: глифы и цветовые коды вычищаются.
* **Антифлуд карты**: длинные ответы режутся на сообщения до 190 символов, отправка не чаще раза в 2,2 секунды, повторы в пределах 10 секунд пропускаются.

## 🚀 Установка и запуск

1. Скачайте репозиторий (или ZIP с GitHub) в отдельную папку:
   ```bat
   git clone https://github.com/goldenfrog-2577/ClaudeBot-Bedrock.git
   ```
2. Запустите `install.bat`: он установит зависимости, журнал установки будет в `out.log`.
3. Для ответов в чате установите Claude Code и один раз войдите в аккаунт:
   ```bat
   curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
   claude
   ```
4. Откройте мир в Minecraft. В настройках мира должна быть включена «Видимость для игроков в локальной сети».
5. Запустите `loopback.bat` от имени администратора и **не закрывайте его окно**. Без него Windows не пускает подключения к Minecraft с того же компьютера.
6. Запустите `start.bat`. При первом запуске он создаст `config.json`: впишите свой ник в `claude.owners` и запустите снова.
7. Выдайте ClaudeBot права оператора в списке игроков, если нужны команды.

Закончили играть — закройте окна ClaudeBot и `loopback.bat`.

### 🔧 Если не подключается
* `diag.bat` проверяет пакет Minecraft, исключения сетевой изоляции и пинг мира по всем адресам. Результат пишется в `out.log`.
* `Ping timed out` — не запущен `loopback.bat` или мир не открыт по сети.
* `Connect timed out` — проверьте в `config.json` значения `"followPort": true` и `"raknetBackend": "raknet-native"`.
* `Claude не ответил` — подробности в `chat.log`, в строке `ERROR claude`. Чаще всего это значит, что вы не вошли в Claude Code.

### 📁 Файлы

| Файл | Что это |
|---|---|
| `bot.js` | сам бот |
| `persona.md` | личность и знание карты для Claude |
| `config.example.json`, `persona.local.example.md`, `bot_account.example.txt` | шаблоны личных файлов: скопируйте без `.example` и заполните |
| `install.bat`, `start.bat` | установка и запуск |
| `loopback.bat`, `loopback_off.bat` | включить и выключить подключения к Minecraft с этого же компьютера |
| `check.bat`, `diag.bat`, `ping.js` | проверки: Node.js, порт мира, пинг |

В репозиторий не попадают `config.json`, `persona.local.md`, `bot_account.txt`, журналы и `node_modules` (см. [.gitignore](./.gitignore)).
